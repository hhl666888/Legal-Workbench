# 合同审阅智能体

已在 `合同审阅智能体.workflow.json` 中完成工作流定义，包含开始、文件读取、三路并行审查、公司名/标题解析、两级企业查询、异常容错、汇总、最终报告和输出节点。

## 导入与手动接入

当前工作区没有可识别的工作流平台连接器，因此无法替你在第三方平台点击创建或填入密钥。模型服务已固定为 DeepSeek（默认 `deepseek-chat`，OpenAI 兼容接口）。请在目标平台导入 JSON（若平台不支持导入，则按 JSON 中的 `nodes` 和 `edges` 建立同名节点），并完成两处 API 适配：

1. 企业信息与经营异常核查已暂时关闭，当前版本不会调用天眼查。

若平台的 IF 节点不支持 `company_info.found`，请将企业存在判断映射为该平台实际的“命中记录数 > 0”字段；不要用单个字段是否缺失判断不存在。

## 验收与测试

上传真实合同后，输入默认审核要求运行。重点检查：文件读取失败是否短路并提示重传；公司名为空或查无企业时是否不调用后续企业接口；企业接口失败时是否仍保留常规和法律审查；最终报告是否包含四个标题及条款依据、风险等级、影响和修改建议。

本次未执行真实合同测试：工作区未提供合同文件。完成 DeepSeek 配置后再用真实合同运行一次即可。

## 网页入口

前端入口为 `index.html`，样式和交互分别在 `styles.css`、`app.js`。当前服务直接读取 `.env.example`（若存在 `.env` 则优先读取 `.env`），请在 `.env.example` 中填写 DeepSeek API Key，然后双击 `启动合同审阅智能体.cmd`。浏览器必须访问 `http://localhost:8789`；若误从本地文件打开，页面会自动跳转到该地址。企业风险核查目前为暂时跳过状态。
